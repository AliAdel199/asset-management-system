# نطاق النظام والوحدات

## وحدات النظام

### 1. وحدة الهيكل الإداري

الوظيفة: تمثيل المؤسسة الرئيسية والجهات والمؤسسات التابعة لها.

العمليات:

1. تعريف المؤسسة الرئيسية.
2. تعريف الجهات التابعة.
3. ربط المستخدمين بالجهات.
4. تحديد نطاق مشاهدة البيانات حسب الجهة.

البيانات المعتمدة:

1. اسم الجهة.
2. نوع الجهة.
3. الجهة الأعلى.
4. حالة الجهة.

ضمن MVP: نعم.

### 2. وحدة المستخدمين والصلاحيات

الوظيفة: إدارة المستخدمين وصلاحياتهم ونطاق وصولهم.

العمليات:

1. إنشاء مستخدم.
2. ربط المستخدم بجهة.
3. منح صلاحيات حسب الدور.
4. تقييد الوصول حسب المؤسسة والجهة.

البيانات المعتمدة:

1. بيانات المستخدم.
2. الجهة المرتبط بها.
3. الدور أو الصلاحيات.

ضمن MVP: نعم.

### 3. وحدة الموجودات

الوظيفة: تسجيل وإدارة بيانات الموجودات الأساسية.

العمليات:

1. تسجيل موجود.
2. تعديل بيانات موجود.
3. عرض تفاصيل موجود.
4. البحث والتصفية.
5. توليد أو ربط QR Code.
6. تغيير الحالة وفق قواعد العمل.

البيانات المعتمدة:

1. تصنيف المادة.
2. طبيعة عمل الجهاز أو الموجود.
3. نوع المادة.
4. القيمة الدفترية.
5. الموديل.
6. المنشأ.
7. سنة الصنع.
8. الرقم التسلسلي.
9. الجهة المجهزة.
10. رقم الوصل.
11. تاريخ التجهيز.
12. الجهة المستلمة.
13. تاريخ الاستلام.
14. تاريخ دخول الخدمة.
15. اسم المستلم.
16. حالة المادة.
17. رقم مستند الصرف.
18. تسلسل اليومية.
19. تاريخ المستند.

ضمن MVP: نعم.

### 4. وحدة التصنيفات والبيانات المرجعية

الوظيفة: إدارة القوائم التي يعتمد عليها تسجيل الموجودات.

العمليات:

1. إدارة تصنيفات الموجودات.
2. إدارة أنواع المواد.
3. إدارة طبيعة الاستخدام.
4. إدارة حالات الموجود بعد اعتمادها.

البيانات المعتمدة:

1. أجهزة.
2. أثاث.
3. سيارات.
4. أراضٍ.
5. مبانٍ.
6. أمثلة أنواع المواد مثل ميز، ثلاجة، حاسوب، كاميرا.
7. أمثلة طبيعة الاستخدام مثل طبية وخدمية.

ضمن MVP: نعم.

### 5. وحدة بيانات التصنيف الخاصة

الوظيفة: حفظ البيانات التي تختلف حسب تصنيف الموجود.

العمليات:

1. تسجيل بيانات السيارات.
2. تسجيل بيانات الأراضي.
3. تسجيل بيانات المباني.

البيانات المعتمدة:

1. السيارات: رقم السيارة، اللوحة، الشاصي، المحرك، العداد، السنوية.
2. الأراضي: القطعة، المقاطعة، المساحة، العنوان، الملكية.
3. المباني: المساحة، عدد الطوابق، سنة الإنشاء، حالة المبنى.

ضمن MVP: جزئيًا، حسب اعتماد شمول الأراضي والمباني بكامل التفاصيل.

### 6. وحدة التسليم والاسترجاع

الوظيفة: متابعة عهدة الموجود لدى الجهات أو الموظفين.

العمليات:

1. تسليم موجود.
2. استرجاع موجود.
3. عرض تاريخ المستلمين.
4. تسجيل ملاحظات التسليم أو الاسترجاع.

البيانات المعتمدة:

1. الموجود.
2. الجهة المستلمة.
3. الموظف المستلم عند توفره.
4. تاريخ التسليم.
5. تاريخ الاسترجاع.
6. الحالة عند التسليم أو الاسترجاع.

ضمن MVP: نعم.

### 7. وحدة النقل بين الجهات

الوظيفة: إدارة حركة الموجود بين الجهات التنظيمية.

العمليات:

1. طلب نقل.
2. اعتماد النقل حسب الإجراء المعتمد.
3. إكمال النقل.
4. عرض سجل النقل.

البيانات المعتمدة:

1. الموجود.
2. الجهة المنقول منها.
3. الجهة المنقول إليها.
4. تاريخ النقل.
5. مستند النقل.
6. حالة الموافقة.

ضمن MVP: نعم، وفق موافقة مركزية مبدئية للنقل بين الجهات.

### 8. وحدة الصيانة

الوظيفة: تسجيل ومتابعة الصيانة الدورية والوقائية والطارئة.

العمليات:

1. إنشاء طلب صيانة.
2. اعتماد أو رفض طلب الصيانة حسب الإجراء المعتمد.
3. تسجيل بيانات العطل.
4. تسجيل القائم بالصيانة.
5. إغلاق طلب الصيانة.
6. تسجيل النتيجة والتكلفة.
7. إصدار تنبيهات الصيانة المستحقة والمتأخرة.

البيانات المعتمدة:

1. الموجود.
2. تاريخ العطل.
3. تاريخ تقديم طلب الصيانة.
4. نوع العطل.
5. القائم بالصيانة.
6. تاريخ إكمال الصيانة.
7. ملاحظات القائم بالصيانة.
8. الجهة المنفذة.
9. التكلفة.
10. نتيجة الصيانة.

ضمن MVP: نعم.

### 9. وحدة المواد وقطع الغيار المصروفة

الوظيفة: تسجيل المواد المصروفة أثناء الصيانة وربطها بعملية الصيانة.

العمليات:

1. إضافة مادة مصروفة.
2. تحديد الكمية وسعر الوحدة.
3. احتساب التكلفة الإجمالية.
4. عرض المواد المصروفة لكل صيانة.

البيانات المعتمدة:

1. المادة.
2. العدد أو الكمية.
3. السعر.
4. المنشأ.
5. عملية الصيانة المرتبطة.

ضمن MVP: نعم.

### 10. وحدة الشطب

الوظيفة: إخراج الموجود من الخدمة رسميًا دون حذف سجله.

العمليات:

1. إنشاء عملية شطب.
2. تسجيل رقم وتاريخ المستند.
3. إرفاق مستند عند توفره.
4. تغيير حالة الموجود إلى مشطوب.
5. عرض سجل الشطب.

البيانات المعتمدة:

1. الموجود.
2. رقم مستند الشطب.
3. تاريخ مستند الشطب.
4. المرفقات.
5. سبب الشطب عند اعتماده.

ضمن MVP: نعم، وفق موافقة جهة مخولة ومستند شطب رسمي.

### 11. وحدة المرفقات

الوظيفة: إدارة الصور ومستندات PDF المرتبطة بالموجودات والعمليات.

العمليات:

1. رفع مرفق.
2. ربط المرفق بموجود أو صيانة أو نقل أو شطب.
3. عرض المرفقات.
4. تقييد نوع وحجم الملف.

البيانات المعتمدة:

1. نوع المرفق.
2. اسم الملف.
3. السجل المرتبط.
4. تاريخ الرفع.
5. المستخدم الرافع.

ضمن MVP: نعم.

### 12. وحدة التقارير

الوظيفة: توفير تقارير تساعد الإدارة والمتابعة والتدقيق.

العمليات:

1. تقرير الموجودات حسب الجهة.
2. تقرير الموجودات حسب التصنيف.
3. تقرير الموجودات حسب الحالة.
4. تقرير الصيانة.
5. تقرير النقل والتسليم.
6. تقرير الشطب.
7. تصدير التقارير إلى PDF وExcel.

البيانات المعتمدة:

1. بيانات الموجودات.
2. بيانات الجهات.
3. بيانات الحركة.
4. بيانات الصيانة.
5. بيانات الشطب.

ضمن MVP: نعم للتقارير الأساسية، مع تعديل نماذج التقارير الرسمية لاحقًا عند تزويد نماذج المؤسسة.

### 13. وحدة سجل العمليات

الوظيفة: حفظ سجل تدقيقي للعمليات المؤثرة.

العمليات:

1. تسجيل الإضافة.
2. تسجيل التعديل.
3. تسجيل التسليم والاسترجاع.
4. تسجيل النقل.
5. تسجيل الصيانة.
6. تسجيل الشطب.
7. عرض السجل لأصحاب الصلاحية.

البيانات المعتمدة:

1. المستخدم.
2. نوع العملية.
3. التاريخ والوقت.
4. السجل المتأثر.
5. ملخص التغيير.

ضمن MVP: نعم.

## الاعتماد بين الوحدات

1. وحدة المستخدمين والصلاحيات تعتمد على وحدة الهيكل الإداري.
2. وحدة الموجودات تعتمد على التصنيفات والبيانات المرجعية.
3. بيانات التصنيف الخاصة تعتمد على وجود سجل موجود أساسي.
4. التسليم والاسترجاع يعتمدان على الموجودات والجهات والموظفين.
5. النقل يعتمد على الموجودات والهيكل الإداري وصلاحيات المستخدم.
6. الصيانة تعتمد على الموجودات.
7. المواد المصروفة تعتمد على الصيانة.
8. الشطب يعتمد على الموجودات والمرفقات عند توفر المستند.
9. المرفقات تعتمد على السجل المرتبط بها.
10. سجل العمليات يعتمد على جميع الوحدات المؤثرة.
11. التقارير تعتمد على بيانات الموجودات والحركة والصيانة والشطب.
