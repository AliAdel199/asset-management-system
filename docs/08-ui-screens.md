# شاشات النظام المقترحة

هذه الوثيقة تحدد شاشات النسخة الأولى على مستوى وظيفي فقط. لا تمثل تصميم واجهة نهائيًا ولا تحتوي على كود.

## مبادئ واجهة المستخدم

1. الواجهة عربية بالكامل وتدعم RTL.
2. الشاشات موجهة للاستخدام الإداري المتكرر.
3. تعرض كل شاشة الإجراءات حسب صلاحيات المستخدم.
4. يجب أن تكون الجداول قابلة للبحث والتصفية.
5. رسائل الخطأ والتنبيه تكون عربية وواضحة.
6. لا تعرض بيانات خارج نطاق جهة المستخدم إلا بصلاحية مركزية.

## شاشة تسجيل الدخول

الغرض:

دخول المستخدم إلى النظام وفق حسابه وصلاحياته.

العناصر:

1. اسم الدخول.
2. كلمة المرور.
3. رسالة خطأ عربية عند فشل الدخول.

## لوحة التحكم

الغرض:

عرض ملخص سريع عن الموجودات والتنبيهات.

العناصر:

1. عدد الموجودات حسب الحالة.
2. عدد الموجودات حسب التصنيف.
3. تنبيهات الصيانة المستحقة.
4. تنبيهات الصيانة المتأخرة.
5. آخر عمليات النقل أو الصيانة حسب الصلاحية.

## شاشة الموجودات

الغرض:

البحث وإدارة سجلات الموجودات.

العناصر:

1. جدول الموجودات.
2. بحث بالرقم الداخلي أو الرقم التسلسلي أو النوع.
3. فلترة حسب الجهة.
4. فلترة حسب التصنيف.
5. فلترة حسب الحالة.
6. زر إضافة موجود حسب الصلاحية.
7. إجراءات عرض وتعديل وتسليم ونقل وصيانة وشطب حسب الصلاحية.

## شاشة إضافة أو تعديل موجود

الغرض:

إدخال بيانات الموجود العامة والخاصة.

الأقسام:

1. البيانات الأساسية.
2. التصنيف ونوع المادة وطبيعة الاستخدام.
3. بيانات التجهيز.
4. بيانات الاستلام ودخول الخدمة.
5. بيانات التصنيف الخاصة.
6. المرفقات الأولية عند الحاجة.

ملاحظات:

1. الرقم الداخلي ينشأ وفق الصيغة المعتمدة.
2. الرقم التسلسلي يمكن تمييزه بأنه غير متوفر.
3. حقول السيارات تظهر فقط عند اختيار تصنيف سيارات.
4. حقول الأراضي والمباني تظهر حسب التصنيف.

## شاشة تفاصيل الموجود

الغرض:

عرض ملف كامل للموجود.

الأقسام:

1. ملخص الموجود والرقم الداخلي وQR Code.
2. البيانات العامة.
3. البيانات الخاصة حسب التصنيف.
4. الجهة الحالية أو المستلم الحالي.
5. سجل التسليم والاسترجاع.
6. سجل النقل.
7. سجل الصيانة.
8. المواد المصروفة.
9. المرفقات.
10. سجل العمليات المرتبط.

الإجراءات:

1. تعديل.
2. تسليم.
3. استرجاع.
4. طلب نقل.
5. طلب صيانة.
6. شطب.
7. رفع مرفق.
8. طباعة أو تصدير بطاقة الموجود.

## شاشة التسليم والاسترجاع

الغرض:

إدارة عهدة الموجود لدى الجهات أو الموظفين.

العناصر:

1. اختيار الموجود.
2. الجهة المستلمة.
3. الموظف المستلم.
4. تاريخ التسليم.
5. تاريخ الاسترجاع.
6. الحالة عند التسليم أو الاسترجاع.
7. الملاحظات.
8. سجل المستلمين السابقين.

## شاشة النقل بين الجهات

الغرض:

إدارة طلبات النقل واعتمادها.

العناصر:

1. رقم الموجود.
2. الجهة المنقول منها.
3. الجهة المنقول إليها.
4. سبب النقل.
5. حالة الطلب.
6. تاريخ الطلب.
7. تاريخ الاعتماد.
8. المرفقات.
9. أزرار الموافقة أو الرفض حسب الصلاحية.

## شاشة الصيانة

الغرض:

إدارة طلبات الصيانة واعتمادها.

العناصر:

1. جدول طلبات الصيانة.
2. فلترة حسب الجهة.
3. فلترة حسب نوع الصيانة.
4. فلترة حسب حالة الطلب (بما فيها بانتظار الموافقة والمرفوضة).
5. فلترة حسب التاريخ.
6. زر إنشاء طلب صيانة.
7. أزرار الموافقة أو الرفض لكل طلب بانتظار الموافقة، حسب الصلاحية.

## شاشة تفاصيل طلب الصيانة

الغرض:

عرض وإدارة طلب صيانة محدد.

الأقسام:

1. بيانات الموجود.
2. بيانات العطل.
3. نوع الصيانة.
4. القائم بالصيانة.
5. الجهة المنفذة.
6. النتيجة والتكلفة.
7. المواد المصروفة.
8. المرفقات.
9. الملاحظات.
10. مقدّم الطلب وحالته، وجهة القرار (المعتمِد أو الرافض) عند البت به.

الإجراءات:

1. أزرار الموافقة أو الرفض حسب الصلاحية، عندما يكون الطلب بانتظار الموافقة.
2. تعديل الطلب.
3. إضافة مادة مصروفة.
4. إكمال الصيانة (بعد الاعتماد فقط).
5. رفع مرفق.

## شاشة الشطب

الغرض:

إدارة عمليات الشطب الرسمية.

العناصر:

1. اختيار الموجود.
2. رقم مستند الشطب.
3. تاريخ مستند الشطب.
4. سبب الشطب.
5. الجهة المخولة.
6. مرفق المستند.
7. زر اعتماد الشطب حسب الصلاحية.

## شاشة المرفقات

الغرض:

عرض وإدارة المرفقات المرتبطة بالسجلات.

العناصر:

1. اسم الملف.
2. نوع الملف.
3. حجم الملف.
4. السجل المرتبط.
5. تاريخ الرفع.
6. المستخدم الرافع.

قواعد العرض:

1. دعم الصور وPDF.
2. تطبيق حد 10MB مبدئيًا.

## شاشة التقارير

الغرض:

توفير التقارير الأساسية والتصدير.

التقارير:

1. الموجودات حسب الجهة.
2. الموجودات حسب التصنيف.
3. الموجودات حسب الحالة.
4. حركة الموجود.
5. الصيانة.
6. الشطب.
7. المرفقات.

العناصر:

1. اختيار نوع التقرير.
2. فلاتر التقرير.
3. عرض النتائج.
4. تصدير إلى PDF.
5. تصدير إلى Excel.

## شاشة المستخدمين والصلاحيات

الغرض:

إدارة مستخدمي النظام وأدوارهم.

العناصر:

1. قائمة المستخدمين.
2. إضافة مستخدم.
3. تعديل مستخدم.
4. ربط المستخدم بجهة.
5. تحديد الدور.
6. تفعيل أو إيقاف المستخدم.

## شاشة الهيكل الإداري

الغرض:

إدارة المؤسسة والجهات التابعة.

العناصر:

1. شجرة الجهات.
2. إضافة جهة.
3. تعديل جهة.
4. تحديد الجهة الأعلى.
5. تحديد رمز الجهة.
6. تفعيل أو إيقاف جهة.

## شاشة الإعدادات والبيانات المرجعية

الغرض:

إدارة القوائم الأساسية.

القوائم:

1. تصنيفات الموجودات.
2. أنواع المواد.
3. طبيعة الاستخدام.
4. حالات الموجود.
5. أنواع الصيانة.
6. دوريات الصيانة.

## شاشة سجل العمليات

الغرض:

عرض العمليات المؤثرة لأغراض التدقيق.

العناصر:

1. المستخدم.
2. نوع العملية.
3. الوحدة.
4. السجل المتأثر.
5. التاريخ والوقت.
6. ملخص العملية.
7. فلاتر بحث.

## أولوية الشاشات في MVP

1. تسجيل الدخول.
2. الهيكل الإداري.
3. المستخدمون والصلاحيات.
4. البيانات المرجعية.
5. الموجودات.
6. تفاصيل الموجود.
7. التسليم والاسترجاع.
8. النقل.
9. الصيانة.
10. الشطب.
11. المرفقات.
12. التقارير.
13. سجل العمليات.
